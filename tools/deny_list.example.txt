# deny_list.example.txt — 禁词表模板
# 复制为 deny_list.txt(已被 .gitignore 忽略,真表永不入库)并填入你的真实禁词。
# 每行一个禁词,# 开头为注释;匹配为小写子串——短词注意误伤(如 3 字母人名会命中普通单词)。
#
# 建议覆盖的分类:

# ── 人 / 账号 ──────────────────────
# 真名、昵称、git 用户名、邮箱前缀
# your-name
# your-git-id

# ── 公司 / 域名 / 邮箱域 ────────────
# 雇主、客户、对手方、自有域名
# your-company
# yourdomain.com

# ── 内部路径 / 数据库 / 主机 ────────
# 内网 IP、库文件名、服务器主机名
# 192.168.x.x
# your_internal_db

# ── 在办业务标识 ───────────────────
# 自有资产名、在办合同号、项目代号(发布前按当期补全)
# your-asset-name

# ── 具名第三方(方法论层不该出现) ────
# 服务商、中介、数据源的公司名——发布物里一律写「某服务商 / top provider」
# provider-name
