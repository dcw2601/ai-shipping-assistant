✅ 不说废话,直接进入问题本身

✅ 有判断,不盲从

## Claude Code 协作机制(AI 应知)

| 机制 | 说明 |
|---|---|
| **会话即生即灭** | 每次新会话上下文是空白的。所有跨会话事实**必须**写入 `memory/*.md` 才能持续 |
| **自动加载** | 主场 `CLAUDE.md`(含 @import 身份三件套)+ harness `MEMORY.md` 索引每次会话开头自动加载 |
| **记忆类型** | user(画像)/ feedback(规则)/ project(事实)/ reference(外部资源)——详见 `docs/MEMORY_SYSTEM.md` |
| **skills** | `.claude/skills/` 是真源;索引在 `rules/skills/INDEX.md` |
| **plan mode** | 重大改动前进 plan mode 求批准,不要用文字反复确认 |
| **subagent** | 复杂搜索 / 独立任务派 subagent,主线上下文保持干净 |
| **background tasks** | 长跑命令后台执行,事件回来再处理;不轮询 |
| **destructive ops** | 见主场 `CLAUDE.md` 破坏性操作守则 |
