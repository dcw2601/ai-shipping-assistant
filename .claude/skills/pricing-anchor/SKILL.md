# pricing-anchor — 先锚价,再撮合

**铁律:任何定价动作的第一步,永远是锚出「这单在今天市场的价格 level」。锚不出来就明说缺口在哪,不许跳过、不许凭感觉直接报数。**

(本 skill 从 dry bulk 船货撮合实战蒸馏,方法论通用于任何「有 peer 成交可比的标的定价」:租船、货运、二手设备、服务报价均适用。示例用航运语言,占位符换成你的领域。)

## 触发(MUST)

- 任何单子的候选 propose / 评审 / 报价建议
- 用户问「这个标的能做到多少 / 该报什么水位」
- 用户问「对方报价合理吗 / 这个 ask 贵不贵」
- 任何价格数字出口之前

## Step 0 — 定价格族

先定这单属于哪条价格带,再在带内微调。价格族由**主变量**决定,不同族之间价差是台阶不是斜坡:

- {{示例:资产年龄段——老龄资产与新资产是两条价格带,同一市场差一个档位;规格只是带内微调}}
- {{示例:航线/区域 × 标的规格段——同一票货,不同规格段是两个价}}
- **口径先定**:按什么单位谈($/unit 还是 $/day?headline 还是 all-in?),定了口径才能比。

## Step 1 — 锚市场价 level(先于一切 propose)

1. **peer 同族**:找同族、同区域、同结构的**近期实际成交**——本周优先。你的成交库 / 记录表是首站;库里不够就明说「锚不出来」,列缺口。
2. **rate 读全**:附加条款(一次性费用 / 附加金 / 交接条件)是价的一部分;**headline ≠ all-in**,附加项摊到周期里再比。
3. **核成交日**:陈 comp 必须对**对应细分指数**(不是大盘篮子)标漂移;单边市里两周前的价不是今天的价。
4. **输出锚**:`peer 区间 X–Y(逐条列:标的/族/日期)→ 本单调整项 → 谈价区间 A–B`。

## Step 2 — 只调可量化差

锚定后,本单与 peer 的每一项差异都要**可量化**才准入算式:

- **规格 / 数量差**:差额通常只折算一部分(对手方让利有限,不全额折),折算率用你自己的历史观察,标 [推断] 直到有数据。
- **位置 / 时间差**:位置差走**引擎真算**(时间 × 成本),不拍脑袋;与 peer 的基点口径对齐了再比。
- **族内底线**:老龄 / 低规格族的合理 ask 比新族低一档——评审对方报价时按**其族**的 peer 比,别拿新族价评老族标的(反之亦然)。

## Step 3 — 这时才 propose / 评审

每条候选带:契合度 + 量化调整项 + **Step 1 的锚价区间**。没有锚价的 propose = 半成品,不出手。

## 禁手(踩过的坑,通用化)

- ❌ **新族成交锚老族标的**(两条价格带,台阶差被当成不存在)
- ❌ **「all-in ÷ 指数 = 固定倍数」外推**(结构项不随指数缩放,倍数外推会系统性虚高)
- ❌ **headline 当 all-in**(附加金 / 附加条款没摊进去,低价假象)
- ❌ **拿大盘篮子指数量单一细分的漂移**(细分单边行情远超篮子均值,陈 comp 校准就错)
- ❌ **无视位置差直接比不同基点的 comp**(位置差是真金白银,必须入算式)
- ❌ **不同口径的成交并排比**($/unit 与 $/day 不换算就对照 = 没对照)

## 基准标的法(可选进阶)

给你的市场定义一个**基准规格标的**(行业指数假设的那个标准规格),把所有具体标的的定价表述为「相对基准的偏离」:指数值 = 基准标的的市场价;具体标的合理价 = 指数 −(准入折价)±(族 / 规格 / 位置各偏离项)。**偏离项一律走计算引擎算,不许拍脑袋**——两次引擎调用的差就是量化偏离。

把基准标的的完整参数录进你的计算库,随时可对表。

## 输出契约

```
族: {{老龄/新族 × 区域 × 口径}}
锚: peer {{X–Y}}({{成交1/成交2/成交3,带日期}})
调整: {{位置 −a}} {{规格 +b}}(引擎算,非拍脑袋)
→ 谈价区间 {{A–B}} · 置信 {{MED}}
```
